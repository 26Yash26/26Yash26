I think in proofs before I think in code. Most of what's here started as a question I wanted to answer for myself — a model, a control loop, a tool that didn't exist yet — rather than something built to be shown off.

Interested in mathematics for its own sake — probability, linear algebra, the kind of problem worth sitting with. Lately that's extended into machine learning and language models, and what it actually takes to turn one of those ideas into something that runs, not just something that demos well.

---

## Repositories

**[garch-volatility-regime-strategy](https://github.com/26Yash26/garch-volatility-regime-strategy)**
A GARCH model classifying market conditions into distinct volatility regimes — an attempt at strategy logic that adapts as conditions change, rather than assuming one static behavior.
`HTML` — time-series modeling, regime classification

**[vol_surface_model](https://github.com/26Yash26/vol_surface_model)**
An SVI (Stochastic Volatility Inspired) surface fitted and calibrated on real SPY options data — a smooth, arbitrage-aware curve pulled out of noisy quotes.
`Jupyter Notebook` — surface fitting, options data

**[GuildRecruitmentPhaseI](https://github.com/26Yash26/GuildRecruitmentPhaseI)**
A backtesting engine built for a recruitment competition, simulating strategy performance against historical data under competition constraints.
`Python` — backtesting, simulation

**[SelfBallBalancingBeam](https://github.com/26Yash26/SelfBallBalancingBeam)**
A real-time feedback control system holding a ball balanced on a beam through continuous sensing and correction. A classic controls problem, worked through end to end.
`C++` — control systems, real-time feedback

**[WebOCR](https://github.com/26Yash26/WebOCR)**
A web-based OCR tool that pulls text straight out of images in the browser.
`Python` — optical character recognition

**[OCR_TTS_App](https://github.com/26Yash26/OCR_TTS_App)**
A mobile app chaining OCR into text-to-speech — point it at text, it reads that text back.
`Kotlin` — OCR, text-to-speech, Android
